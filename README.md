## 🎯 Project Overview

**Cyborg Event 2026** is a sophisticated, full-stack web application designed to showcase the intersection of Formula 1 engineering and digital innovation. This project demonstrates advanced frontend development skills including 3D graphics, real-time animations, interactive UI/UX, and responsive design—all crafted for the TechFest 2026 College Ambassador Program at IIT Bombay.

### Key Features

- **3D Formula 1 Car Visualization** - Built with Three.js, featuring dynamic lighting, materials, and scroll-driven animations
- **Interactive Hero Section** - Rotating scenario animations with GSAP timeline effects
- **Advanced Animations** - Smooth entrance animations, scroll triggers, and real-time particle effects
- **Audio Engineering** - Custom Web Audio API implementations (engine revs, hover effects, click sounds)
- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **SEO Optimized** - Comprehensive schema.org structured data for Google and AI recognition
- **Performance Focused** - Optimized rendering, efficient animations, and minimal dependencies

## 🔧 Installation & Setup

### Clone Repository
```bash

cd cyborg-event-2026
```

### Local Development
```bash
# Option 1: Live Server (VS Code)
# Install "Live Server" extension and run

# Option 2: Python HTTP Server
python -m http.server 8000

# Option 3: Node.js HTTP Server
npx http-server
```
